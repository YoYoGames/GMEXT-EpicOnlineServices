Progression Snapshot¶

Epic Online Services: Progression Snapshot Interface

The Progression Snapshot Interface stores player-specific progress data to support Epic account merging. When a user with two separate Epic accounts merges them, the Epic overlay can present a snapshot of their game progress on each account, letting them choose which progression to keep.

Functions¶

These functions are provided for handling progression snapshots:

  • eos_progression_snapshot_begin_snapshot
  • eos_progression_snapshot_add_progression
  • eos_progression_snapshot_end_snapshot
  • eos_progression_snapshot_submit_snapshot
  • eos_progression_snapshot_delete_snapshot

Structs¶

These are the structs used by this module:

  • EpicProgressionSnapshotSubmitSnapshotCallbackInfo
  • EpicProgressionSnapshotDeleteSnapshotCallbackInfo

eos_progression_snapshot_begin_snapshot¶

Epic Online Services Function: EOS_ProgressionSnapshot_BeginSnapshot

This function creates a new progression-snapshot resource for a given user and returns a snapshot ID. Use that ID with eos_progression_snapshot_add_progression, eos_progression_snapshot_end_snapshot, eos_progression_snapshot_submit_snapshot, and eos_progression_snapshot_delete_snapshot.


Syntax:

eos_progression_snapshot_begin_snapshot(local_user_id)
Argument Type Description
local_user_id String The Product User ID of the local user the snapshot belongs to.


Returns:

Real

Note

Returns -1 if the snapshot could not be created (invalid local_user_id, or the interface is unavailable).


Example:

var _snapshot_id = eos_progression_snapshot_begin_snapshot(local_user_id);
eos_progression_snapshot_add_progression(_snapshot_id, "PlayerLevel", "12");
The above code begins a snapshot and adds one progression key/value pair to it.

eos_progression_snapshot_add_progression¶

Epic Online Services Function: EOS_ProgressionSnapshot_AddProgression

This function stores a key/value pair in memory for a given snapshot. If called multiple times with the same key, the last call wins. Typically you call this several times, then finish with a single call to eos_progression_snapshot_submit_snapshot.


Syntax:

eos_progression_snapshot_add_progression(snapshot_id, key, value)
Argument Type Description
snapshot_id Real The snapshot ID received from eos_progression_snapshot_begin_snapshot.
key String The key of the progression entry.
value String The value of the progression entry.


Returns:

EpicResult


Example:

var _snapshot_id = eos_progression_snapshot_begin_snapshot(local_user_id);
eos_progression_snapshot_add_progression(_snapshot_id, "PlayerLevel", "12");
eos_progression_snapshot_add_progression(_snapshot_id, "PlayerClass", "Warrior");
The above code adds two progression key/value pairs to a snapshot.

eos_progression_snapshot_end_snapshot¶

Epic Online Services Function: EOS_ProgressionSnapshot_EndSnapshot

This function cleans up and releases resources associated with a progression snapshot ID.

Note

Call this after eos_progression_snapshot_submit_snapshot has completed.


Syntax:

eos_progression_snapshot_end_snapshot(snapshot_id)
Argument Type Description
snapshot_id Real The snapshot ID received from eos_progression_snapshot_begin_snapshot.


Returns:

EpicResult


Example:

eos_progression_snapshot_end_snapshot(snapshot_id);
The above code releases the resources held by snapshot_id.

eos_progression_snapshot_submit_snapshot¶

Epic Online Services Function: EOS_ProgressionSnapshot_SubmitSnapshot

This function saves the previously added key/value pairs for a snapshot to the backend service.

Note

This overwrites any prior progression data already stored for the user.

This function operates asynchronously, which means that it does not immediately return the requested result. Instead, upon completion of the task, it will trigger the Callback.


Syntax:

eos_progression_snapshot_submit_snapshot(snapshot_id, callback=undefined)
Argument Type Description
snapshot_id Real The snapshot ID received from eos_progression_snapshot_begin_snapshot.
callback Function Called once the submission completes.


Returns:

N/A


Triggers:

Callback

Called with a single result struct once the submission completes.

Key Type Description
result EpicProgressionSnapshotSubmitSnapshotCallbackInfo


Example:

eos_progression_snapshot_submit_snapshot(snapshot_id, function(_result)
{
    if (_result.result_code == EpicResult.Success)
    {
        eos_progression_snapshot_end_snapshot(snapshot_id);
    }
});
The above code submits the snapshot and, on success, releases it.

eos_progression_snapshot_delete_snapshot¶

Epic Online Services Function: EOS_ProgressionSnapshot_DeleteSnapshot

This function wipes all previously submitted progression data for a user from the backend service. Any progression data added locally but not yet submitted is unaffected.

This function operates asynchronously, which means that it does not immediately return the requested result. Instead, upon completion of the task, it will trigger the Callback.


Syntax:

eos_progression_snapshot_delete_snapshot(local_user_id, callback=undefined)
Argument Type Description
local_user_id String The Product User ID of the local user whose submitted progression data should be deleted.
callback Function Called once the deletion completes.


Returns:

N/A


Triggers:

Callback

Called with a single result struct once the deletion completes.

Key Type Description
result EpicProgressionSnapshotDeleteSnapshotCallbackInfo


Example:

eos_progression_snapshot_delete_snapshot(local_user_id, function(_result)
{
    show_debug_message("Delete result: " + string(_result.result_code));
});
The above code deletes all submitted progression data for the local user.
