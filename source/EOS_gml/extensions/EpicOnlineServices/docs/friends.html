Friends¶

Epic Online Services Interface: Friends Interface

The Friends Interface exposes the local user's Epic friends list - its own social graph, independent from any platform-native friends list. This only covers Epic Account friendships; for the platform-native friends UI overlay see User Interface.

Note

You must call eos_friends_query_friends at least once before the cached accessor functions below return anything useful.

Functions¶

Provided functions:

  • eos_friends_query_friends
  • eos_friends_get_friends_count
  • eos_friends_get_friend_at_index
  • eos_friends_get_status
  • eos_friends_add_notify_friends_update
  • eos_friends_remove_notify_friends_update

Structs¶

These are the structs used by this API:

  • EpicFriendsQueryFriendsCallbackInfo

These are the constants used by this API:

  • EpicFriendsStatus

eos_friends_query_friends¶

Epic Online Services Function: EOS_Friends_QueryFriends

Starts an asynchronous task that reads the local user's friends list from the backend and caches it locally. You must call this at least once for a given local_user_id before eos_friends_get_friends_count/eos_friends_get_friend_at_index/eos_friends_get_status return anything meaningful for that user.

This function operates asynchronously, which means that it does not immediately return the requested result. Instead, upon completion of the task, it will trigger the Callback.


Syntax:

eos_friends_query_friends(local_user_id, callback=undefined)
Argument Type Description
local_user_id String The Epic Account ID of the local, logged-in user whose friends list is being queried.
callback Function Called once with the result. See the callback event below.


Returns:

N/A


Triggers:

Callback

Fires once, after the friends list has been retrieved (or the query has failed).

Key Type Description
result EpicFriendsQueryFriendsCallbackInfo


Example:

eos_friends_query_friends(local_user_id, function(_result)
{
    if (_result.result_code == EpicResult.Success)
    {
        var _count = eos_friends_get_friends_count(_result.local_user_id);
        show_debug_message($"Friend count: {_count}");
    }
});
The above code queries the local user's friends list, then reads the cached friend count once the query completes.

eos_friends_get_friends_count¶

Epic Online Services Function: EOS_Friends_GetFriendsCount

Returns the number of friends cached for the given local user, from the last successful eos_friends_query_friends.


Syntax:

eos_friends_get_friends_count(local_user_id)
Argument Type Description
local_user_id String The Epic Account ID of the local, logged-in user.


Returns:

Real

eos_friends_get_friend_at_index¶

Epic Online Services Function: EOS_Friends_GetFriendAtIndex

Returns the Epic Account ID of the cached friend at the given index. Use eos_friends_get_friends_count to get the valid index range.


Syntax:

eos_friends_get_friend_at_index(local_user_id, index)
Argument Type Description
local_user_id String The Epic Account ID of the local, logged-in user.
index Real Index into the cached friends list, in the range [0, [eos_friends_get_friends_count](friends.md#eos_friends_get_friends_count) - 1].


Returns:

String

Note

Returns an empty string if the index is out of range.

eos_friends_get_status¶

Epic Online Services Function: EOS_Friends_GetStatus

Returns the cached friendship status between a local user and a target user.


Syntax:

eos_friends_get_status(local_user_id, target_user_id)
Argument Type Description
local_user_id String The Epic Account ID of the local, logged-in user.
target_user_id String The Epic Account ID of the user to check the friendship status of.


Returns:

EpicFriendsStatus


Example:

if (eos_friends_get_status(local_user_id, target_user_id) == EpicFriendsStatus.Friends)
{
    show_debug_message("Already friends!");
}
The above code checks whether the local user and a target user are already friends.

eos_friends_add_notify_friends_update¶

Epic Online Services Function: EOS_Friends_AddNotifyFriendsUpdate

Registers to be notified whenever a friend is added, removed, or has an invite sent/received/accepted between local users of this client and any other user. If the returned notification ID is valid, you must call eos_friends_remove_notify_friends_update with it once you no longer need the notification (e.g. on logout).

This function operates asynchronously, which means that it does not immediately return the requested result. Instead, upon completion of the task, it will trigger the Callback.


Syntax:

eos_friends_add_notify_friends_update(callback=undefined)
Argument Type Description
callback Function Called every time a friend status change is received. See the callback event below.


Returns:

Real

A notification ID, or 0 if registration failed.


Triggers:

Callback

Fires every time a friendship status changes for any local user tracked by this client.

Key Type Description
result EpicFriendsFriendsUpdateCallbackInfo

EpicFriendsStatus¶

Epic Online Services Enum: EOS_EFriendsStatus

The relationship between the local user and another user.

These constants are referenced by the following functions:

  • eos_friends_get_status

These constants are referenced by the following structs:

  • EpicFriendsFriendsUpdateCallbackInfo


Member Description
NotFriends The users are not friends and there is no pending invite.
InviteSent The local user has sent an invite to the other user, awaiting response.
InviteReceived The local user has received an invite from the other user, awaiting response.
Friends The users are friends.

EpicFriendsFriendsUpdateCallbackInfo¶

Delivered by the eos_friends_add_notify_friends_update callback whenever a friendship status changes.

This struct is referenced by the following functions:

  • eos_friends_add_notify_friends_update


Member Type Description
local_user_id String The Epic Account ID of the local user this change applies to.
target_user_id String The Epic Account ID of the other user whose relationship with local_user_id changed.
previous_status EpicFriendsStatus The friendship status before this change.
current_status EpicFriendsStatus The friendship status after this change.
