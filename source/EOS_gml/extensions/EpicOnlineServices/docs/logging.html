Logging

Epic Online Services Interface: Logging Interface

Routes the SDK's own diagnostic log output to a GML callback, and controls how verbose each category is. This is independent of the extension's own Log Level build option (see Extension Options), which only affects the extension's own startup diagnostics.

Functions

Provided functions:

  • eos_logging_set_callback
  • eos_logging_clear_callback
  • eos_logging_set_log_level

Structs

These are the structs used by this API:

eos_logging_set_callback

Epic Online Services Function: EOS_Logging_SetCallback

Registers a callback to receive every log message the SDK produces, across all categories. Call eos_logging_set_log_level to control which categories/levels actually reach it.

Warning

Unlike every other callback in this extension, this one is NOT guaranteed to fire on the main thread during eos_platform_tick - the SDK can invoke it from an internal worker thread. Do not touch instances, rooms, or any other main-thread-only GML state directly from this callback; buffer the message (e.g. into a ds_queue) and drain it from a Step event instead.

This function operates asynchronously, which means that it does not immediately return the requested result. Instead, upon completion of the task, it will trigger the Callback.


Syntax:

eos_logging_set_callback(callback=undefined)
Argument Type Description
callback Function The function to call for every log message.


Returns:

N/A


Triggers:

Callback

Called once per log message.

Key Type Description
message EpicLoggingMessage The log message.


Example:

eos_logging_set_callback(function(_message)
{
    show_debug_message($"[{_message.category}] {_message.message}");
});

eos_logging_clear_callback

Epic Online Services Function: EOS_Logging_SetCallback

Unregisters the callback set by eos_logging_set_callback. Safe to call even if no callback is currently registered.


Syntax:

eos_logging_clear_callback()


Returns:

N/A

eos_logging_set_log_level

Epic Online Services Function: EOS_Logging_SetLogLevel

Sets the logging level for a specific logging category (or every category at once).

Note

By default all log categories are set to callback for Warning, Error, and Fatal.


Syntax:

eos_logging_set_log_level(log_category, log_level)
Argument Type Description
log_category EpicLogCategory The category to configure. Use EpicLogCategory.AllCategories to configure every category at once.
log_level EpicLogLevel The verbosity level to use for that category.


Returns:

EpicResult


Example:

eos_logging_set_log_level(EpicLogCategory.AllCategories, EpicLogLevel.Off);
The above turns off logging for every category.

EpicLogLevel

Epic Online Services Enum: EOS_ELogLevel

The verbosity levels usable with eos_logging_set_log_level. A log message is only sent to the eos_logging_set_callback callback if its own level is less than or equal to the configured level for its category.

These constants are referenced by the following functions:

  • eos_logging_set_log_level

These constants are referenced by the following structs:

  • EpicLoggingMessage


Member Description
Off No log messages.
Fatal Fatal errors only.
Error Errors and above.
Warning Warnings and above.
Info Informational messages and above.
Verbose Verbose messages and above.
VeryVerbose Every log message.
