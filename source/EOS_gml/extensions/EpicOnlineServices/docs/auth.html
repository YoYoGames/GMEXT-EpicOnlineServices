Auth

Epic Online Services Interface: Auth Interface

The Auth Interface lets players log into their Epic Account (EAS) from your game, unlocking Friends, Presence, UserInfo, and Ecom. Most games also call eos_connect_login (see Connect) right after a successful Auth login to obtain a Product User ID usable with the rest of this extension's gameplay-facing services (Lobby, Sessions, Stats, ...).

eos_auth_login

Epic Online Services Function: EOS_Auth_Login

Logs in / authenticates a local user against Epic Account Services (EAS) using the given credentials. The callback fires once with a EpicAuthLoginCallbackInfo.

Note

The scope flags you pass must correspond exactly to the ones configured for your product on the Developer Portal. See Permissions.

Note

If the credentials match an external account with no Epic Account linked yet, the callback's result_code is EpicResult.InvalidUser and has_continuance_token is true - pass continuance_token_id into eos_auth_link_account to complete the link. See the External Login Flow Guide on the Logging In page.

This function operates asynchronously, which means that it does not immediately return the requested result. Instead, upon completion of the task, it will trigger the Callback.


Syntax:

eos_auth_login(credentials_id, credentials_token, credentials_type, external_credential_type, scope_flags, login_flags, callback=undefined)
Argument Type Description
credentials_id String ID for the credentials, meaning depends on credentials_type (often empty for exchange-code/portal logins).
credentials_token String Credentials or token for the login, meaning depends on credentials_type.
credentials_type EpicLoginCredentialType The login method to use.
external_credential_type EpicExternalCredentialType Identity provider to use when credentials_type is EpicLoginCredentialType.ExternalAuth. Ignored otherwise, but a value must still be passed - see Connect for the full list.
scope_flags EpicAuthScopeFlags Bitwise-OR (|) of the permissions to request from the user during login.
login_flags EpicAuthLoginFlags Bitwise-OR (|) of login behaviour flags.
callback Function Called once with the login result.


Returns:

N/A


Triggers:

Callback

Fires once with the outcome of the login attempt.

Key Type Description
result EpicAuthLoginCallbackInfo


Example:

eos_auth_login(
    "", code,
    EpicLoginCredentialType.ExchangeCode,
    EpicExternalCredentialType.Epic,
    EpicAuthScopeFlags.BasicProfile | EpicAuthScopeFlags.FriendsList | EpicAuthScopeFlags.Presence,
    EpicAuthLoginFlags.NoFlags,
    function(_result)
    {
        if (_result.result_code == EpicResult.Success)
        {
            global.local_user_id = _result.selected_account_id;
        }
        else if (_result.result_code == EpicResult.InvalidUser && _result.has_continuance_token)
        {
            eos_auth_link_account(_result.continuance_token_id, "", EpicLinkAccountFlags.NoFlags, link_callback);
        }
    }
);

eos_auth_link_account

Epic Online Services Function: EOS_Auth_LinkAccount

Continues a pending eos_auth_login attempt by linking the external account behind continuance_token_id to an Epic Account. On success the user ends up logged in. This commits the external account to the Epic Account and cannot be undone through the SDK.

This function operates asynchronously, which means that it does not immediately return the requested result. Instead, upon completion of the task, it will trigger the Callback.


Syntax:

eos_auth_link_account(continuance_token_id, local_user_id, link_account_flags, callback=undefined)
Argument Type Description
continuance_token_id Real Continuance token handle obtained from a prior eos_auth_login callback (has_continuance_token was true).
local_user_id String Epic Account ID of an already-logged-in local user to link this external account to. Pass an empty string to let the user pick/create an Epic Account instead.
link_account_flags EpicLinkAccountFlags Bitwise-OR (|) of link behaviour flags.
callback Function Called once linking completes.


Returns:

N/A


Triggers:

Callback

Fires once with the outcome of the link attempt.

Key Type Description
result EpicAuthLinkAccountCallbackInfo


Example:

eos_auth_link_account(continuance_token_id, "", EpicLinkAccountFlags.NoFlags, function(_result)
{
    if (_result.result_code == EpicResult.Success) global.local_user_id = _result.selected_account_id;
});

eos_auth_copy_id_token

Epic Online Services Function: EOS_Auth_CopyIdToken

Fetches a locally-cached ID token for an Epic Account ID. ID tokens are the recommended way to securely prove a user's identity to your own backend or other online services - prefer this over eos_auth_copy_user_auth_token.


Syntax:

eos_auth_copy_id_token(local_user_id, target_account_id)
Argument Type Description
local_user_id String Epic Account ID of the local, logged-in user.
target_account_id String Epic Account ID the token should describe - usually local_user_id's own selected_account_id, or another account ID merged with it.


Returns:

EpicAuthIdToken

Returns undefined if no ID token is cached for target_account_id - call eos_auth_query_id_token first for any account other than the local user's own selected account ID.


Example:

var _token = eos_auth_copy_id_token(global.local_user_id, global.local_user_id);
if (!is_undefined(_token)) global.jwt = _token.json_web_token;

eos_auth_copy_user_auth_token

Epic Online Services Function: EOS_Auth_CopyUserAuthToken

Fetches the locally-cached user auth token for a logged-in local user. Whoever holds this token can act on the user's behalf, so prefer eos_auth_copy_id_token unless you specifically need this token (e.g. to hand it to a launcher/backend, or as the persistent-auth token to store yourself on Console).


Syntax:

eos_auth_copy_user_auth_token(local_user_id)
Argument Type Description
local_user_id String Epic Account ID of the local, logged-in user.


Returns:

EpicAuthUserAuthToken

Returns undefined if local_user_id is not currently logged in.


Example:

var _token = eos_auth_copy_user_auth_token(global.local_user_id);
if (!is_undefined(_token)) global.access_token = _token.access_token;

eos_auth_query_id_token

Epic Online Services Function: EOS_Auth_QueryIdToken

Queries the backend for an ID token describing target_account_id, one of the accounts merged with the local user's Epic Account. Once this completes, fetch the token with eos_auth_copy_id_token. Not needed for the local user's own selected account ID - that token is always already cached.

This function operates asynchronously, which means that it does not immediately return the requested result. Instead, upon completion of the task, it will trigger the Callback.


Syntax:

eos_auth_query_id_token(local_user_id, target_account_id, callback=undefined)
Argument Type Description
local_user_id String Epic Account ID of the local, logged-in user.
target_account_id String Epic Account ID to query an ID token for.
callback Function Called once the query completes.


Returns:

N/A


Triggers:

Callback

Fires once with the outcome of the query. Fetch the token itself afterwards with eos_auth_copy_id_token.

Key Type Description
result EpicAuthQueryIdTokenCallbackInfo


Example:

eos_auth_query_id_token(global.local_user_id, target_account_id, function(_result)
{
    if (_result.result_code == EpicResult.Success)
    {
        var _token = eos_auth_copy_id_token(_result.local_user_id, _result.target_account_id);
    }
});

EpicLoginCredentialType

Epic Online Services Enum: EOS_ELoginCredentialType

The login method to use with eos_auth_login. Availability depends on platform and the permissions granted to your client.

These constants are referenced by the following functions:

  • eos_auth_login


Member Description
Password Direct username/password login. Restricted to internal Epic testing.
ExchangeCode A short-lived, one-time exchange code (e.g. handed to your game by the Epic Games Launcher). Must be consumed promptly, before it expires.
PersistentAuth Desktop/Mobile only - logs in using a long-lived access token previously stored on the device by a prior login. Returns EpicResult.InvalidAuth if no valid stored token exists.
DeviceCode Deprecated, no longer used.
Developer Login using named credentials hosted by the EOS SDK Developer Authentication Tool (local development only).
RefreshToken A refresh token obtained from a previous eos_auth_login in another local process - used by launcher-to-game-client handoff flows.
AccountPortal Desktop/Mobile only - opens the Epic Account Portal for the user to log in interactively.
ExternalAuth Login using an external platform's credentials (Steam, PlayStation Network, Xbox Live, Nintendo, etc. - see external_credential_type). The primary login method on Console.
