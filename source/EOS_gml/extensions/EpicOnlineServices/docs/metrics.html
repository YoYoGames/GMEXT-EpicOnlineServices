Metrics

Epic Online Services Interface: Metrics Interface

The Metrics Interface reports your game's play-session activity to the Game Analytics dashboard in the Developer Portal, tracking active client/server instances and past local-player sessions.

Functions

These functions are provided for handling metrics:

  • eos_metrics_begin_player_session
  • eos_metrics_end_player_session

Constants

These are the constants used by this module:

  • EpicMetricsAccountIdType
  • EpicUserControllerType

eos_metrics_begin_player_session

Epic Online Services Function: EOS_Metrics_BeginPlayerSession

This function logs the start of a new game session for a local player. Call it whenever the game client joins a new multiplayer, peer-to-peer, or single-player session. Each call must be matched with a corresponding call to eos_metrics_end_player_session.


Syntax:

eos_metrics_begin_player_session(account_id, account_id_type, display_name, controller_type, server_ip, game_session_id)
Argument Type Description
account_id String An Epic Account ID or an external service account ID, depending on account_id_type.
account_id_type EpicMetricsAccountIdType Whether account_id is an Epic Account ID or an external account ID.
display_name String The in-game display name for the user.
controller_type EpicUserControllerType The user's game controller type.
server_ip String IP address of the game server hosting the session. Pass an empty string for a local/host session.
game_session_id String Application-defined match/session identifier shown in the Played Sessions listing on the user's profile dashboard. Pass an empty string if unused.


Returns:

EpicResult


Example:

var _result = eos_metrics_begin_player_session(
    account_id,
    EpicMetricsAccountIdType.Epic,
    "PlayerOne",
    EpicUserControllerType.MouseKeyboard,
    "",
    "");

if (_result != EpicResult.Success)
{
    show_debug_message("eos_metrics_begin_player_session failed");
}
The above code begins a metrics session for the local Epic account, playing with mouse and keyboard on a local session.

eos_metrics_end_player_session

Epic Online Services Function: EOS_Metrics_EndPlayerSession

This function logs the end of a game session for a local player. Call once when the game client leaves the session started by eos_metrics_begin_player_session.


Syntax:

eos_metrics_end_player_session(account_id, account_id_type, controller_type, server_ip, game_session_id)
Argument Type Description
account_id String The same account identifier passed to eos_metrics_begin_player_session for this session.
account_id_type EpicMetricsAccountIdType Whether account_id is an Epic Account ID or an external account ID. Must match what was passed to eos_metrics_begin_player_session.
controller_type EpicUserControllerType The user's game controller type.
server_ip String IP address of the game server hosting the session.
game_session_id String Application-defined match/session identifier.


Returns:

EpicResult

Note

The SDK's End Player Session call only requires the account and its type; controller_type/server_ip/game_session_id are accepted by this function for symmetry with eos_metrics_begin_player_session but are not sent as part of the end-session request.


Example:

var _result = eos_metrics_end_player_session(
    account_id,
    EpicMetricsAccountIdType.Epic,
    EpicUserControllerType.MouseKeyboard,
    "",
    "");

show_debug_message("eos_metrics_end_player_session: " + string(_result));
The above code ends the metrics session started earlier for the local Epic account.

EpicUserControllerType

Epic Online Services Enum: EOS_EUserControllerType

Describes the type of controller in use during the player session.

These constants are referenced by the following functions:

  • eos_metrics_begin_player_session
  • eos_metrics_end_player_session


Member Description
Unknown The controller type is unknown.
MouseKeyboard Mouse and keyboard.
GamepadControl Gamepad.
TouchControl Touch controls.

EpicMetricsAccountIdType

Epic Online Services Enum: EOS_EMetricsAccountIdType

Describes which kind of account identifier is being passed to eos_metrics_begin_player_session/eos_metrics_end_player_session.

These constants are referenced by the following functions:

  • eos_metrics_begin_player_session
  • eos_metrics_end_player_session


Member Description
Epic An Epic Account ID.
External An external service account ID.
