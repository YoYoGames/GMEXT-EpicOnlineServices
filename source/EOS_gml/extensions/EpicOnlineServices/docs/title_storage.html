Title Storage¶

Epic Online Services Interface: Title Storage Interface

The Title Storage Interface lets you download developer-managed files (patch notes, remote config, DLC manifests, and similar title-wide content) that you upload through the Dev Portal. Unlike Player Data Storage, this storage is read-only from the game's side and isn't tied to a specific player. Files are downloaded straight to a local path on disk - the extension streams the transfer itself, so you never handle the raw bytes directly in GML.

Note

local_user_id may be passed as an empty string "" on every function in this module - Title Storage content isn't per-player. Supplying a real Product User ID lets the SDK apply any per-user entitlement checks configured for tagged premium content; leave it empty otherwise.

Note

Reading files requires an Encryption Key to be configured in the extension's Extension Options. See Extension Options.

eos_titlestorage_query_file¶

Epic Online Services Function: EOS_TitleStorage_QueryFile

Requests the metadata for a specific file in title storage, updating the local metadata cache with the results. This does not download the file's contents - call eos_titlestorage_read_file for that.

This function operates asynchronously, which means that it does not immediately return the requested result. Instead, upon completion of the task, it will trigger the Callback.


Syntax:

eos_titlestorage_query_file(local_user_id, filename, callback=undefined)
Argument Type Description
local_user_id String The Product User ID of the user making the request. May be "" - see the local_user_id note on Title Storage.
filename String The name of the file to query.
callback Function A function to call once the request completes. See the callback event below.


Returns:

N/A


Triggers:

Callback

Called once, when the query completes.

Key Type Description
result EpicTitleStorageQueryFileCallbackInfo

eos_titlestorage_query_file_list¶

Epic Online Services Function: EOS_TitleStorage_QueryFileList

Requests the metadata for every file in title storage tagged with any of the given tags, updating the local metadata cache. Use eos_titlestorage_get_file_metadata_count and eos_titlestorage_copy_file_metadata_at_index to read the results once the callback fires.

This function operates asynchronously, which means that it does not immediately return the requested result. Instead, upon completion of the task, it will trigger the Callback.


Syntax:

eos_titlestorage_query_file_list(local_user_id, tags, callback=undefined)
Argument Type Description
local_user_id String The Product User ID of the user making the request. May be "" - see the local_user_id note on Title Storage.
tags Array of String Tags previously assigned to files in the Dev Portal, used to filter which files are returned. Pass an empty array to match every file.
callback Function A function to call once the request completes. See the callback event below.


Returns:

N/A


Triggers:

Callback

Called once, when the query completes.

Key Type Description
result EpicTitleStorageQueryFileListCallbackInfo


Example:

eos_titlestorage_query_file_list(local_user_id, ["patch-notes"], function(_result)
{
    if (_result.result_code == EpicResult.Success)
    {
        show_debug_message($"{_result.file_count} title storage file(s) found");
    }
});
The above code queries every title storage file tagged "patch-notes".

eos_titlestorage_copy_file_metadata_at_index¶

Epic Online Services Function: EOS_TitleStorage_CopyFileMetadataAtIndex

Fetches a locally cached metadata struct for a file, by index. index must be less than the value returned by eos_titlestorage_get_file_metadata_count.

Note

This reads from the local cache populated by the last query call - it does not talk to the backend.


Syntax:

eos_titlestorage_copy_file_metadata_at_index(local_user_id, index)
Argument Type Description
local_user_id String The Product User ID of the user making the request. May be "" - see the local_user_id note on Title Storage.
index Real Index into the cached file list, from 0 to eos_titlestorage_get_file_metadata_count - 1.


Returns:

EpicTitleStorageFileMetadata

Note

Returns undefined if index is out of range or the underlying SDK call fails - check eos_api_last_error for details.

eos_titlestorage_read_file¶

Epic Online Services Function: EOS_TitleStorage_ReadFile

Downloads a file from title storage straight to a local path on disk, streaming it in chunks rather than buffering the whole thing in memory.

Note

output_path is a real filesystem path, not a GML buffer - the extension writes the downloaded bytes to disk itself. Load the file back into your game with GML's own file functions once the callback fires with EpicResult.Success.

Warning

If the transfer fails or is cancelled part-way through, the extension removes the partially-written file at output_path rather than leaving a corrupt fragment behind - it will never silently replace a previously-good file at that path with a broken one.

This function operates asynchronously, which means that it does not immediately return the requested result. Instead, upon completion of the task, it will trigger the Callback.


Syntax:

eos_titlestorage_read_file(local_user_id, filename, output_path, callback=undefined, progress_callback=undefined)
Argument Type Description
local_user_id String The Product User ID of the user making the request. May be "" - see the local_user_id note on Title Storage.
filename String The name of the file to read.
output_path String Local filesystem path the downloaded file is written to.
callback Function A function to call once the download completes (success or failure). See the callback event below.
progress_callback Function A function to call repeatedly while the download is in progress. See the callback_progress event below.


Returns:

N/A


Triggers:

Callback

Called once, when the download finishes or fails.

Key Type Description
result EpicTitleStorageReadFileCallbackInfo


Callback - Progress

Called zero or more times while the download is in progress, before the callback event fires.

Key Type Description
result EpicTitleStorageReadFileProgressCallbackInfo

eos_titlestorage_file_transfer_request_cancel_request¶

Epic Online Services Function: EOS_TitleStorageFileTransferRequest_CancelRequest

Cancels an in-progress eos_titlestorage_read_file transfer for the given filename. The transfer's callback will still fire, reporting a non-success result code.


Syntax:

eos_titlestorage_file_transfer_request_cancel_request(filename)
Argument Type Description
filename String The filename of the transfer to cancel, as passed to eos_titlestorage_read_file.

> [!NOTE]
>
> Fails silently (sets eos_api_last_error) if there is no active transfer for this filename.


Returns:

N/A

eos_titlestorage_delete_cache¶

Epic Online Services Function: EOS_TitleStorage_DeleteCache

Removes previously cached data for a given user from the local filesystem cache used internally by the SDK. This does not touch the copies stored on Epic's backend.

This function operates asynchronously, which means that it does not immediately return the requested result. Instead, upon completion of the task, it will trigger the Callback.


Syntax:

eos_titlestorage_delete_cache(local_user_id, callback=undefined)

local_user_id String The Product User ID of the user making the request. May be "" - see the local_user_id note on Title Storage.
callback Function A function to call once the request completes. See the callback event below.


Returns:

N/A


Triggers:

Callback

Called once, when the cache-clear operation completes.

Key Type Description
result EpicTitleStorageDeleteCacheCallbackInfo

EpicTitleStorageReadResult¶

Epic Online Services Enum: EOS_TitleStorage_EReadResult - describes how a single chunk of a file read completed, at the SDK level.

Note

This extension handles read-chunk streaming to disk internally (see eos_titlestorage_read_file) - this constant isn't currently surfaced through any GML function or callback parameter, it's documented here for completeness against the generated API surface.


Member Description
ContinueReading The read operation should continue.
FailRequest The read operation should terminate in failure.
CancelRequest The read operation should terminate as cancelled.

EpicTitleStorageFileMetadata¶

Cached metadata for a single file in title storage, as last reported by eos_titlestorage_query_file/eos_titlestorage_query_file_list.

This struct is referenced by the following functions:

  • eos_titlestorage_copy_file_metadata_at_index
  • eos_titlestorage_copy_file_metadata_by_filename


Member Type Description
file_size_bytes Real Size, in bytes, of the file as stored (possibly encrypted) in the cloud.
md5_hash String MD5 hash of the file's contents.
filename String Name of the file.
unencrypted_data_size_bytes Real Size, in bytes, of the file's contents once decrypted.
