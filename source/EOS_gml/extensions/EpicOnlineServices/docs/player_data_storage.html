Player Data Storage

Epic Online Services Interface: Player Data Storage Interface

The Player Data Storage Interface lets you store and retrieve per-player binary files in the cloud, so a player's save data and settings follow them between devices. Files are read from and written to a local path on disk - the extension streams the transfer itself, so you never handle the raw bytes directly in GML.

Note

Reading/writing files requires an Encryption Key to be configured in the extension's Extension Options. See Extension Options.

eos_playerdatastorage_query_file

Epic Online Services Function: EOS_PlayerDataStorage_QueryFile

Requests the metadata for a specific file in the requesting user's player data storage, updating the local metadata cache with the results. This does not download the file's contents - call eos_playerdatastorage_read_file for that once you know the file exists via eos_playerdatastorage_copy_file_metadata_by_filename.

This function operates asynchronously, which means that it does not immediately return the requested result. Instead, upon completion of the task, it will trigger the Callback.


Syntax:

eos_playerdatastorage_query_file(local_user_id, filename, callback=undefined)
Argument Type Description
local_user_id String The Product User ID of the user who owns the file to query.
filename String The name of the file to query.
callback Function A function to call once the request completes. See the callback event below.


Returns:

N/A


Triggers:

Callback

Called once, when the query completes.

Key Type Description
result EpicPlayerDataStorageQueryFileCallbackInfo


Example:

eos_playerdatastorage_query_file(local_user_id, "save1.dat", function(_result)
{
    if (_result.result_code == EpicResult.Success)
    {
        var _meta = eos_playerdatastorage_copy_file_metadata_by_filename(local_user_id, "save1.dat");
        show_debug_message($"save1.dat is {_meta.file_size_bytes} bytes");
    }
});
The above code queries a single file's metadata, then reads it back out of the local cache once the query succeeds.

eos_playerdatastorage_copy_file_metadata_at_index

Epic Online Services Function: EOS_PlayerDataStorage_CopyFileMetadataAtIndex

Fetches a locally cached metadata struct for a file, by index. index must be less than the value returned by eos_playerdatastorage_get_file_metadata_count.

Note

This reads from the local cache populated by the last query call - it does not talk to the backend.


Syntax:

eos_playerdatastorage_copy_file_metadata_at_index(local_user_id, index)
Argument Type Description
local_user_id String The Product User ID of the user who owns the cached file list.
index Real Index into the cached file list, from 0 to eos_playerdatastorage_get_file_metadata_count - 1.


Returns:

EpicPlayerDataStorageFileMetadata

Note

Returns undefined if index is out of range or the underlying SDK call fails - check eos_api_last_error for details.

eos_playerdatastorage_read_file

Epic Online Services Function: EOS_PlayerDataStorage_ReadFile

Downloads a file from player data storage straight to a local path on disk, streaming it in chunks rather than buffering the whole thing in memory.

Note

output_path is a real filesystem path, not a GML buffer - the extension writes the downloaded bytes to disk itself. Load the file back into your game with GML's own file functions once the callback fires with EpicResult.Success.

Warning

If the transfer fails or is cancelled part-way through, the extension removes the partially-written file at output_path rather than leaving a corrupt fragment behind - it will never silently replace a previously-good file at that path with a broken one.

This function operates asynchronously, which means that it does not immediately return the requested result. Instead, upon completion of the task, it will trigger the Callback, or ${event.callback_progress}.


Syntax:

eos_playerdatastorage_read_file(local_user_id, filename, output_path, callback=undefined, progress_callback=undefined)
Argument Type Description
local_user_id String The Product User ID of the user who owns the file.
filename String The name of the file to read.
output_path String Local filesystem path the downloaded file is written to.
callback Function A function to call once the download completes (success or failure). See the callback event below.
progress_callback Function A function to call repeatedly while the download is in progress. See the callback_progress event below.


Returns:

N/A


Triggers:

Callback

Called once, when the download finishes or fails.

Key Type Description
result EpicPlayerDataStorageReadFileCallbackInfo


${event.callback_progress}

Called zero or more times while the download is in progress, before the callback event fires.

Key Type Description
result EpicPlayerDataStorageReadFileProgressCallbackInfo


Example:

eos_playerdatastorage_read_file(local_user_id, "save1.dat", working_directory + "save1.dat",
function(_result)
{
    if (_result.result_code == EpicResult.Success)
    {
        show_debug_message("save1.dat downloaded");
    }
},
function(_progress)
{
    show_debug_message($"{_progress.bytes_transferred} / {_progress.total_file_size_bytes} bytes");
});
The above code downloads save1.dat to the game's working directory, printing progress as it comes in.

eos_playerdatastorage_write_file

Epic Online Services Function: EOS_PlayerDataStorage_WriteFile

Uploads a local file on disk to player data storage, streaming it in chunks.

Note

input_path is a real filesystem path, not a GML buffer - the extension reads the file itself before uploading. An empty or unreadable input_path fails immediately (eos_api_last_error is set) without starting a transfer or firing callback.

This function operates asynchronously, which means that it does not immediately return the requested result. Instead, upon completion of the task, it will trigger the Callback, or ${event.callback_progress}.


Syntax:

eos_playerdatastorage_write_file(local_user_id, filename, input_path, callback=undefined, progress_callback=undefined)
Argument Type Description
local_user_id String The Product User ID of the user who will own the file.
filename String The name to give the file in player data storage.
input_path String Local filesystem path of the file to upload.
callback Function A function to call once the upload completes (success or failure). See the callback event below.
progress_callback Function A function to call repeatedly while the upload is in progress. See the callback_progress event below.


Returns:

N/A


Triggers:

Callback

Called once, when the upload finishes or fails.

Key Type Description
result EpicPlayerDataStorageWriteFileCallbackInfo


${event.callback_progress}

Called zero or more times while the upload is in progress, before the callback event fires.

Key Type Description
result EpicPlayerDataStorageWriteFileProgressCallbackInfo

eos_playerdatastorage_file_transfer_request_cancel_request

Epic Online Services Function: EOS_PlayerDataStorageFileTransferRequest_CancelRequest

Cancels an in-progress eos_playerdatastorage_read_file or eos_playerdatastorage_write_file transfer for the given filename. The transfer's callback will still fire, reporting a non-success result code.


Syntax:

eos_playerdatastorage_file_transfer_request_cancel_request(filename)
Argument Type Description
filename String The filename of the transfer to cancel, as passed to eos_playerdatastorage_read_file/eos_playerdatastorage_write_file.

> [!NOTE]
>
> Fails silently (sets eos_api_last_error) if there is no active transfer for this filename.


Returns:

N/A

EpicPlayerDataStorageReadResult

Epic Online Services Enum: EOS_PlayerDataStorage_EReadResult - describes how a single chunk of a file read completed, at the SDK level.

Note

This extension handles read-chunk streaming to disk internally (see eos_playerdatastorage_read_file) - this constant isn't currently surfaced through any GML function or callback parameter, it's documented here for completeness against the generated API surface.


Member Description
ContinueReading The read operation should continue.
FailRequest The read operation should terminate in failure.
CancelRequest The read operation should terminate as cancelled.

EpicPlayerDataStorageFileMetadata

Cached metadata for a single file in player data storage, as last reported by eos_playerdatastorage_query_file/eos_playerdatastorage_query_file_list.

This struct is referenced by the following functions:

  • eos_playerdatastorage_copy_file_metadata_at_index
  • eos_playerdatastorage_copy_file_metadata_by_filename


Member Type Description
file_size_bytes Real Size, in bytes, of the file as stored (possibly encrypted) in the cloud.
md5_hash String MD5 hash of the file's contents.
filename String Name of the file.
last_modified_time Real Unix timestamp of the file's last modification.
unencrypted_data_size_bytes Real Size, in bytes, of the file's contents once decrypted.
