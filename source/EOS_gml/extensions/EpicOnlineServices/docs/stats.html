Stats

Epic Online Services Interface: Stats Interface

The Stats Interface provides the ability to manage users' stats for an application - any statistical data you want to track, such as items collected, fastest completion time, or number of victories. Stats are commonly used to drive Achievements unlock conditions and Leaderboards rankings.

Functions

These functions are provided for handling stats:

  • eos_stats_ingest_stat
  • eos_stats_query_stats
  • eos_stats_get_stats_count
  • eos_stats_copy_stat_by_index
  • eos_stats_copy_stat_by_name

Structs

These are the structs used by this module:

  • EpicStatsStat
  • EpicStatsIngestStatCallbackInfo
  • EpicStatsQueryStatsCallbackInfo

eos_stats_ingest_stat

Epic Online Services Function: EOS_Stats_IngestStat

This function ingests a stat by the amount specified in ingest_amount. When the operation completes and the callback fires, the stat will have been uploaded to the backend for processing. The stat may not be reflected immediately, and an achievement built on top of it may take a while to unlock once the stat has actually landed.

This function operates asynchronously, which means that it does not immediately return the requested result. Instead, upon completion of the task, it will trigger the Callback.


Syntax:

eos_stats_ingest_stat(local_user_id, target_user_id, stat_name, ingest_amount, callback=undefined)
Argument Type Description
local_user_id String The Product User ID of the local user requesting the ingest.
target_user_id String The Product User ID for the user whose stat is being ingested.
stat_name String Name of the stat to ingest, as configured in the Developer Portal.
ingest_amount Real Amount to ingest for the stat.
callback Function Called once the ingest completes.


Returns:

N/A


Triggers:

Callback

Called with a single result struct once the ingest completes.

Key Type Description
result EpicStatsIngestStatCallbackInfo


Example:

eos_stats_ingest_stat(local_user_id, local_user_id, "Enemies_Killed", 1, function(_result)
{
    if (_result.result_code == EpicResult.Success)
    {
        show_debug_message("Stat ingested");
    }
});
The above code ingests one unit of the Enemies_Killed stat for the local user.

eos_stats_query_stats

Epic Online Services Function: EOS_Stats_QueryStats

This function queries a list of stats for a specific player and caches the result. Once the callback fires with EpicResult.Success, use eos_stats_get_stats_count, eos_stats_copy_stat_by_index, or eos_stats_copy_stat_by_name to read the cached values.

Note

This function always queries every stat configured for the product; there is no way to narrow the query to specific stat names.

This function operates asynchronously, which means that it does not immediately return the requested result. Instead, upon completion of the task, it will trigger the Callback.


Syntax:

eos_stats_query_stats(local_user_id, target_user_id, start_time, end_time, callback=undefined)
Argument Type Description
local_user_id String The Product User ID of the local user requesting the stats.
target_user_id String The Product User ID for the user whose stats are being retrieved.
start_time Real The POSIX timestamp to start the query range at.
end_time Real The POSIX timestamp to end the query range at.
callback Function Called once the query completes.


Returns:

N/A


Triggers:

Callback

Called with a single result struct once the query completes.

Key Type Description
result EpicStatsQueryStatsCallbackInfo


Example:

eos_stats_query_stats(local_user_id, local_user_id, 0, 0, function(_result)
{
    if (_result.result_code == EpicResult.Success)
    {
        var _count = eos_stats_get_stats_count(_result.target_user_id);
        for (var i = 0; i < _count; i++)
        {
            var _stat = eos_stats_copy_stat_by_index(_result.target_user_id, i);
            show_debug_message(_stat.name + " = " + string(_stat.value));
        }
    }
});
The above code queries all stats for the local user and prints their cached values.

eos_stats_get_stats_count

Epic Online Services Function: EOS_Stats_GetStatsCount

This function fetches the number of stats cached locally for a user. Requires a previous successful call to eos_stats_query_stats.


Syntax:

eos_stats_get_stats_count(target_user_id)
Argument Type Description
target_user_id String The Product User ID whose cached stat count is being read.


Returns:

Real


Example:

var _count = eos_stats_get_stats_count(target_user_id);
The above code returns the number of cached stats for target_user_id.

eos_stats_copy_stat_by_index

Epic Online Services Function: EOS_Stats_CopyStatByIndex

This function copies a cached stat by index. Requires a previous successful call to eos_stats_query_stats.


Syntax:

eos_stats_copy_stat_by_index(target_user_id, index)
Argument Type Description
target_user_id String The Product User ID who owns the stat.
index Real Index of the stat to retrieve from the cache, between 0 and eos_stats_get_stats_count minus one.


Returns:

EpicStatsStat

Note

Returns undefined if the index is out of range or the stat could not be copied.


Example:

var _count = eos_stats_get_stats_count(target_user_id);
for (var i = 0; i < _count; i++)
{
    var _stat = eos_stats_copy_stat_by_index(target_user_id, i);
    show_debug_message(_stat.name + " = " + string(_stat.value));
}
The above code iterates and prints every cached stat for target_user_id.

eos_stats_copy_stat_by_name

Epic Online Services Function: EOS_Stats_CopyStatByName

This function copies a cached stat by name. Requires a previous successful call to eos_stats_query_stats.


Syntax:

eos_stats_copy_stat_by_name(target_user_id, name)
Argument Type Description
target_user_id String The Product User ID who owns the stat.
name String Name of the stat to retrieve from the cache.


Returns:

EpicStatsStat

Note

Returns undefined if no cached stat matches name.


Example:

var _stat = eos_stats_copy_stat_by_name(target_user_id, "Enemies_Killed");
if (!is_undefined(_stat)) show_debug_message(string(_stat.value));
The above code reads the cached Enemies_Killed stat for target_user_id.

EpicStatsStat

A single cached stat value, returned by eos_stats_copy_stat_by_index/eos_stats_copy_stat_by_name.

This struct is referenced by the following functions:

  • eos_stats_copy_stat_by_index
  • eos_stats_copy_stat_by_name


Member Type Description
name String The name of the stat.
start_time Real The POSIX timestamp for the start of the query range this value was aggregated over.
end_time Real The POSIX timestamp for the end of the query range this value was aggregated over.
value Real The stat's current aggregated value.
