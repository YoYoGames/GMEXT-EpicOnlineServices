Sanctions

Epic Online Services Interface: Sanctions Interface

The Sanctions Interface manages punitive actions taken against your users, such as temporary or permanent bans from gameplay or communication. You define the disciplinary actions for your product and how to handle negative behaviour.

These functions are provided for handling sanctions:

  • eos_sanctions_query_active_player_sanctions

eos_sanctions_query_active_player_sanctions

Epic Online Services Function: EOS_Sanctions_QueryActivePlayerSanctions

This function starts an asynchronous query to retrieve any active sanctions for a specified user. Once the callback fires with EpicResult.Success, use eos_sanctions_get_player_sanction_count and eos_sanctions_copy_player_sanction_by_index to read the cached results.

This function operates asynchronously, which means that it does not immediately return the requested result. Instead, upon completion of the task, it will trigger the Callback.


Syntax:

eos_sanctions_query_active_player_sanctions(local_user_id, target_user_id, callback=undefined)
Argument Type Description
local_user_id String The Product User ID of the local user who initiated this request. Dedicated servers should pass an empty string.
target_user_id String The Product User ID of the user whose active sanctions are being queried.
callback Function Called once the query completes.


Returns:

N/A


Triggers:

Callback

Called with a single result struct once the query completes.

Key Type Description
result EpicSanctionsQueryActivePlayerSanctionsCallbackInfo


Example:

eos_sanctions_query_active_player_sanctions(local_user_id, target_user_id, function(_result)
{
    if (_result.result_code == EpicResult.Success)
    {
        var _count = eos_sanctions_get_player_sanction_count(_result.target_user_id);
        for (var i = 0; i < _count; i++)
        {
            var _sanction = eos_sanctions_copy_player_sanction_by_index(_result.target_user_id, i);
            show_debug_message(_sanction.action);
        }
    }
});
The above code queries active sanctions for target_user_id and prints each sanction's action.

eos_sanctions_get_player_sanction_count

Epic Online Services Function: EOS_Sanctions_GetPlayerSanctionCount

This function fetches the number of active sanctions cached locally for a user. Requires a previous successful call to eos_sanctions_query_active_player_sanctions.


Syntax:

eos_sanctions_get_player_sanction_count(target_user_id)
Argument Type Description
target_user_id String The Product User ID whose cached sanction count is being read.


Returns:

Real


Example:

var _count = eos_sanctions_get_player_sanction_count(target_user_id);
The above code returns the number of active sanctions cached for target_user_id.

eos_sanctions_copy_player_sanction_by_index

Epic Online Services Function: EOS_Sanctions_CopyPlayerSanctionByIndex

This function copies a cached active sanction by index. Requires a previous successful call to eos_sanctions_query_active_player_sanctions.


Syntax:

eos_sanctions_copy_player_sanction_by_index(target_user_id, index)
Argument Type Description
target_user_id String The Product User ID who owns the sanction.
index Real Index of the sanction to retrieve from the cache, between 0 and eos_sanctions_get_player_sanction_count minus one.


Returns:

EpicSanctionsPlayerSanction

Note

Returns undefined if the index is out of range or the sanction could not be copied.


Example:

var _count = eos_sanctions_get_player_sanction_count(target_user_id);
for (var i = 0; i < _count; i++)
{
    var _sanction = eos_sanctions_copy_player_sanction_by_index(target_user_id, i);
    show_debug_message(_sanction.action);
}
The above code iterates and prints every active sanction for target_user_id.

eos_sanctions_create_player_sanction_appeal

Epic Online Services Function: EOS_Sanctions_CreatePlayerSanctionAppeal

This function submits an appeal for a previously placed sanction.

This function operates asynchronously, which means that it does not immediately return the requested result. Instead, upon completion of the task, it will trigger the Callback.


Syntax:

eos_sanctions_create_player_sanction_appeal(local_user_id, reference_id, reason, callback=undefined)
Argument Type Description
local_user_id String The Product User ID of the local user filing the appeal.
reference_id String The sanction's reference_id (from EpicSanctionsPlayerSanction) being appealed.
reason EpicSanctionAppealReason The reason for the appeal.
callback Function Called once the appeal has been submitted.


Returns:

N/A


Triggers:

Callback

Called with a single result struct once the appeal has been submitted.

Key Type Description
result EpicSanctionsCreatePlayerSanctionAppealCallbackInfo


Example:

eos_sanctions_create_player_sanction_appeal(local_user_id, reference_id, EpicSanctionAppealReason.CompromisedAccount, function(_result)
{
    show_debug_message("Appeal result: " + string(_result.result_code));
});
The above code appeals a sanction, claiming the account was compromised.

EpicSanctionAppealReason

Epic Online Services Enum: EOS_ESanctionAppealReason

The reason given for an appeal submitted via eos_sanctions_create_player_sanction_appeal.

These constants are referenced by the following functions:

  • eos_sanctions_create_player_sanction_appeal


Member Description
Invalid Invalid reason, do not use.
IncorrectSanction The sanction was placed incorrectly.
CompromisedAccount The account was compromised at the time of the offending action.
UnfairPunishment The punishment is considered unfair for the offense.
AppealForForgiveness A general request for forgiveness/leniency.
