User Info

Epic Online Services Interface: UserInfo Interface

The UserInfo Interface retrieves public account information - display name, country, linked external accounts - for any Epic user, not just friends. See Friends for the local user's own friends list, and Connect for EpicExternalAccountType/linking a user's own external accounts.

Note

You must call eos_user_info_query_user_info for a given target user before the cached accessor functions below return anything for them.

Provided functions:

eos_user_info_query_user_info

Epic Online Services Function: EOS_UserInfo_QueryUserInfo

Starts an asynchronous task that fetches a target user's basic info (display name, country, preferred language, nickname) from the backend and caches it locally. You must call this before eos_user_info_copy_user_info returns anything for that pair of users.

This function operates asynchronously, which means that it does not immediately return the requested result. Instead, upon completion of the task, it will trigger the Callback.


Syntax:

eos_user_info_query_user_info(local_user_id, target_user_id, callback=undefined)
Argument Type Description
local_user_id String The Epic Account ID of the local, logged-in user making the request.
target_user_id String The Epic Account ID of the user to query info for.
callback Function Called once with the result. See the callback event below.


Returns:

N/A


Triggers:

Callback

Fires once, after the query completes (or fails).

Key Type Description
result EpicUserInfoQueryUserInfoCallbackInfo


Example:

eos_user_info_query_user_info(local_user_id, target_user_id, function(_result)
{
    if (_result.result_code == EpicResult.Success)
    {
        var _info = eos_user_info_copy_user_info(_result.local_user_id, _result.target_user_id);
        show_debug_message($"Display name: {_info.display_name}");
    }
});
The above code queries a target user's info, then reads the cached display name once the query completes.

eos_user_info_copy_user_info

Epic Online Services Function: EOS_UserInfo_CopyUserInfo

Returns the cached info for a target user, from the last successful eos_user_info_query_user_info.


Syntax:

eos_user_info_copy_user_info(local_user_id, target_user_id)
Argument Type Description
local_user_id String The Epic Account ID of the local, logged-in user.
target_user_id String The Epic Account ID of the user whose cached info to copy.


Returns:

EpicUserInfo

Note

Returns undefined if no info is cached for this pair of users - call eos_user_info_query_user_info first.

eos_user_info_get_local_platform_type

Epic Online Services Function: EOS_UserInfo_GetLocalPlatformType

Returns the online platform type of the current running instance of the game.

Note

The SDK exposes this as a set of loose integer constants rather than a real enum, so this function returns a plain real value. Known values: 0 Unknown, 100 Epic, 1000 PSN, 2000 Nintendo, 3000 Xbox Live.


Syntax:

eos_user_info_get_local_platform_type()


Returns:

Real

eos_user_info_copy_best_display_name

Epic Online Services Function: EOS_UserInfo_CopyBestDisplayName

Returns the best available display name string for a target user - the SDK internally picks the most appropriate display name source (Epic display name, platform display name, etc.) for the pair of users involved, which can differ from the raw display_name field on EpicUserInfo.


Syntax:

eos_user_info_copy_best_display_name(local_user_id, target_user_id)
Argument Type Description
local_user_id String The Epic Account ID of the local, logged-in user.
target_user_id String The Epic Account ID of the user to get the best display name for.


Returns:

String

Note

Returns an empty string if a best display name could not be determined for this pair of users.

eos_user_info_copy_external_user_info_by_index

Epic Online Services Function: EOS_UserInfo_CopyExternalUserInfoByIndex

Returns a target user's cached linked external account info (e.g. a linked Steam or PSN account) at the given index.


Syntax:

eos_user_info_copy_external_user_info_by_index(local_user_id, target_user_id, index)
Argument Type Description
local_user_id String The Epic Account ID of the local, logged-in user.
target_user_id String The Epic Account ID of the user to look up external account info for.
index Real Index into the cached external account list.


Returns:

EpicUserInfoExternalUserInfo

Note

Returns undefined if the index is out of range.

eos_user_info_copy_external_user_info_by_account_type

Epic Online Services Function: EOS_UserInfo_CopyExternalUserInfoByAccountType

Returns a target user's cached linked external account info for a specific platform, e.g. their linked Steam account.


Syntax:

eos_user_info_copy_external_user_info_by_account_type(local_user_id, target_user_id, account_type)
Argument Type Description
local_user_id String The Epic Account ID of the local, logged-in user.
target_user_id String The Epic Account ID of the user to look up external account info for.
account_type EpicExternalAccountType The external platform to look up.


Returns:

EpicUserInfoExternalUserInfo

Note

Returns undefined if the target user has no linked account of this type.

Returns a target user's cached linked external account info matching a specific external account ID.

EpicUserInfo

A user's basic public info, as cached by eos_user_info_query_user_info.

This struct is referenced by the following functions:

  • eos_user_info_copy_user_info


Member Type Description
user_id String The Epic Account ID this info is for.
country String The user's country, as an ISO 3166 country code, if available.
display_name String The user's raw Epic display name.
preferred_language String The user's preferred language, as an ISO 639 language code, if available.
nickname String A per-relationship nickname (e.g. a friend nickname) the local user has set for this user, if any.
