Reports

Epic Online Services Interface: Reports Interface

The Reports Interface lets players report other players' bad behavior directly from your game, forwarding the report to Epic for review.

eos_reports_send_player_behavior_report

Epic Online Services Function: EOS_Reports_SendPlayerBehaviorReport

This function sends a player behavior report about another player to the backend service for review.

This function operates asynchronously, which means that it does not immediately return the requested result. Instead, upon completion of the task, it will trigger the Callback.


Syntax:

eos_reports_send_player_behavior_report(reporter_user_id, reported_user_id, category, message, context, callback=undefined)
Argument Type Description
reporter_user_id String The Product User ID of the local user submitting the report.
reported_user_id String The Product User ID of the user being reported.
category EpicPlayerReportsCategory The category that best describes the reported behavior.
message String A human-readable description of what happened, to include with the report.
context String Additional application-defined context for the report (e.g. a JSON blob of the match/session state).
callback Function Called once the report has been submitted.


Returns:

N/A


Triggers:

Callback

Called with a single result struct once the report has been submitted.

Key Type Description
result EpicReportsSendPlayerBehaviorReportCallbackInfo


Example:

eos_reports_send_player_behavior_report(
    local_user_id,
    reported_user_id,
    EpicPlayerReportsCategory.Cheating,
    "Was using an aimbot in the last match.",
    "",
    function(_result)
    {
        if (_result.result_code == EpicResult.Success)
        {
            show_debug_message("Report submitted");
        }
    });
The above code reports reported_user_id for cheating.

EpicPlayerReportsCategory

Epic Online Services Enum: EOS_EPlayerReportsCategory

The category of behavior being reported via eos_reports_send_player_behavior_report.

These constants are referenced by the following functions:

  • eos_reports_send_player_behavior_report


Member Description
Invalid Invalid category, do not use.
Cheating The reported user was cheating.
Exploiting The reported user was exploiting a bug for unfair advantage.
OffensiveProfile The reported user's profile (name/avatar/bio) is offensive.
VerbalAbuse The reported user engaged in verbal abuse.
Scamming The reported user attempted to scam another player.
Spamming The reported user was spamming.
Other Any other reason not covered above.
