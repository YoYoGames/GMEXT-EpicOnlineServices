Leaderboards

Epic Online Services Interface: Leaderboards Interface

The Leaderboards Interface lets you query leaderboard definitions, top ranks, and specific users' scores. Leaderboards are driven by stats - see Stats for ingesting the values leaderboards rank.

Note

Query before you read: eos_leaderboards_query_definitions populates the definition accessors, eos_leaderboards_query_ranks populates the record accessors, and eos_leaderboards_query_user_scores populates the user-score accessors.

eos_leaderboards_query_definitions

Epic Online Services Function: EOS_Leaderboards_QueryLeaderboardDefinitions

Queries the list of leaderboard definitions for the running application. Call this before using eos_leaderboards_get_definition_count, eos_leaderboards_copy_definition_by_index or eos_leaderboards_copy_definition_by_id.

This function operates asynchronously, which means that it does not immediately return the requested result. Instead, upon completion of the task, it will trigger the Callback.


Syntax:

eos_leaderboards_query_definitions(local_user_id, start_time, end_time, callback=undefined)
Argument Type Description
local_user_id String The Product User ID of the user querying the definitions.
start_time Real Unix timestamp to restrict the query to, or macros's EOS_LEADERBOARDS_TIME_UNDEFINED for no lower bound.
end_time Real Unix timestamp to restrict the query to, or macros's EOS_LEADERBOARDS_TIME_UNDEFINED for no upper bound.
callback Function Function invoked when the query completes.


Returns:

N/A


Triggers:

Callback

Called once when the definitions query completes.

Key Type Description
result EpicLeaderboardsQueryDefinitionsCallbackInfo The result of the query.


Example:

eos_leaderboards_query_definitions(local_user_id, EOS_LEADERBOARDS_TIME_UNDEFINED, EOS_LEADERBOARDS_TIME_UNDEFINED, function(_result)
{
    if (_result.result_code == EpicResult.Success)
    {
        show_debug_message($"Loaded {eos_leaderboards_get_definition_count()} leaderboard definitions");
    }
});
The above code queries every leaderboard definition, with no time restriction.

eos_leaderboards_query_ranks

Epic Online Services Function: EOS_Leaderboards_QueryLeaderboardRanks

Queries the top-ranked entries (records) for a single leaderboard. Call this before using eos_leaderboards_get_record_count, eos_leaderboards_copy_record_by_index or eos_leaderboards_copy_record_by_user_id.

This function operates asynchronously, which means that it does not immediately return the requested result. Instead, upon completion of the task, it will trigger the Callback.


Syntax:

eos_leaderboards_query_ranks(local_user_id, leaderboard_id, callback=undefined)
Argument Type Description
local_user_id String The Product User ID of the user querying the ranks.
leaderboard_id String ID of the leaderboard to query, as returned by EpicLeaderboardDefinition's leaderboard_id.
callback Function Function invoked when the query completes.


Returns:

N/A


Triggers:

Callback

Called once when the ranks query completes.

Key Type Description
result EpicLeaderboardsQueryRanksCallbackInfo The result of the query.


Example:

eos_leaderboards_query_ranks(local_user_id, "high_score", function(_result)
{
    if (_result.result_code == EpicResult.Success)
    {
        show_debug_message($"Loaded {eos_leaderboards_get_record_count()} records for {_result.leaderboard_id}");
    }
});
The above code queries the top records for the "high_score" leaderboard.

eos_leaderboards_query_user_scores

Epic Online Services Function: EOS_Leaderboards_QueryLeaderboardUserScores

Queries scores for a specific set of users across one or more stats, regardless of where those users rank. Use this instead of eos_leaderboards_query_ranks when you want specific players' scores (e.g. a friends list) rather than the overall top ranks. Call this before using eos_leaderboards_get_user_score_count and eos_leaderboards_copy_user_score_by_index.

This function operates asynchronously, which means that it does not immediately return the requested result. Instead, upon completion of the task, it will trigger the Callback.


Syntax:

eos_leaderboards_query_user_scores(local_user_id, target_user_ids, stat_queries, start_time, end_time, callback=undefined)
Argument Type Description
local_user_id String The Product User ID of the user querying the scores.
target_user_ids Array of String The Product User IDs to fetch scores for.
stat_queries Array of EpicLeaderboardStatQuery The stats to query scores for, and how to aggregate them.
start_time Real Unix timestamp to restrict the query to, or macros's EOS_LEADERBOARDS_TIME_UNDEFINED for no lower bound.
end_time Real Unix timestamp to restrict the query to, or macros's EOS_LEADERBOARDS_TIME_UNDEFINED for no upper bound.
callback Function Function invoked when the query completes.


Returns:

N/A


Triggers:

Callback

Called once when the user-scores query completes.

Key Type Description
result EpicLeaderboardsQueryUserScoresCallbackInfo The result of the query.

Note

Results for every queried stat are read back together with eos_leaderboards_get_user_score_count/eos_leaderboards_copy_user_score_by_index, keyed by stat_name - call the accessor once per stat you queried.


Example:

var _stat_queries = [{ stat_name: "high_score", aggregation: EpicLeaderboardAggregation.Max }];

eos_leaderboards_query_user_scores(local_user_id, [friend_a_id, friend_b_id], _stat_queries, EOS_LEADERBOARDS_TIME_UNDEFINED, EOS_LEADERBOARDS_TIME_UNDEFINED, function(_result)
{
    if (_result.result_code == EpicResult.Success)
    {
        var _count = eos_leaderboards_get_user_score_count("high_score");
        for (var i = 0; i < _count; i++)
        {
            var _score = eos_leaderboards_copy_user_score_by_index("high_score", i);
            show_debug_message($"{_score.user_id}: {_score.score}");
        }
    }
});
The above code queries two friends' high scores.

eos_leaderboards_copy_definition_by_index

Epic Online Services Function: EOS_Leaderboards_CopyLeaderboardDefinitionByIndex

Fetches a leaderboard definition by index, from the cached data populated by eos_leaderboards_query_definitions.


Syntax:

eos_leaderboards_copy_definition_by_index(index)
Argument Type Description
index Real Index of the definition, between 0 and eos_leaderboards_get_definition_count - 1.


Returns:

EpicLeaderboardDefinition

Warning

Returns undefined if index is out of range or no definitions have been queried yet - check eos_api_last_error for the reason.

EpicLeaderboardAggregation

Epic Online Services Enum: EOS_ELeaderboardAggregation

How a leaderboard or a user-scores query combines multiple stat ingests into a single score.

These constants are referenced by the following structs:

  • EpicLeaderboardStatQuery


Member Description
Min The lowest ingested value.
Max The highest ingested value.
Sum The sum of all ingested values.
Latest The most recently ingested value.
