Achievements¶

Epic Online Services Interface: Achievements Interface

The Achievements Interface lets you query achievement definitions and player progress, unlock achievements directly, and listen for unlocks that happen automatically as stats cross their thresholds.

Note

Query the achievement definitions with eos_achievements_query_definitions and a player's progress with eos_achievements_query_player_achievements before reading either - the accessor functions below read from the most recently cached query result.

eos_achievements_query_definitions¶

Epic Online Services Function: EOS_Achievements_QueryDefinitions

Queries the list of achievement definitions for the running application, optionally including localized text for the locale configured for local_user_id. Call this once at startup (or whenever you need fresh definitions) before using eos_achievements_get_achievement_definition_count, eos_achievements_copy_achievement_definition_by_index, eos_achievements_copy_achievement_definition_by_id or eos_achievements_copy_achievement_definition_v2_by_index - those accessors read from the results of the most recent successful query.

This function operates asynchronously, which means that it does not immediately return the requested result. Instead, upon completion of the task, it will trigger the Callback.


Syntax:

eos_achievements_query_definitions(local_user_id, callback=undefined)
Argument Type Description
local_user_id String The Product User ID of the user querying the definitions.
callback Function Function invoked when the query completes.


Returns:

N/A


Triggers:

Callback

Called once when the definitions query completes.

Key Type Description
result EpicAchievementsQueryDefinitionsCallbackInfo The result of the query.


Example:

eos_achievements_query_definitions(local_user_id, function(_result)
{
    if (_result.result_code == EpicResult.Success)
    {
        var _count = eos_achievements_get_achievement_definition_count();
        show_debug_message($"Loaded {_count} achievement definitions");
    }
});
The above code queries the achievement definitions and reports how many were loaded once the query succeeds.

eos_achievements_query_player_achievements¶

Epic Online Services Function: EOS_Achievements_QueryPlayerAchievements

Queries a player's achievement progress. target_user_id doesn't need to be the same as local_user_id - you can query another player's progress as long as local_user_id has permission to see it. Call this before using eos_achievements_get_player_achievement_count, eos_achievements_copy_player_achievement_by_index or eos_achievements_copy_player_achievement_by_id for that target_user_id.

This function operates asynchronously, which means that it does not immediately return the requested result. Instead, upon completion of the task, it will trigger the Callback.


Syntax:

eos_achievements_query_player_achievements(local_user_id, target_user_id, callback=undefined)
Argument Type Description
local_user_id String The Product User ID of the user performing the query.
target_user_id String The Product User ID of the player whose achievements to query.
callback Function Function invoked when the query completes.


Returns:

N/A


Triggers:

Callback

Called once when the query completes.

Key Type Description
result EpicAchievementsQueryPlayerAchievementsCallbackInfo The result of the query.


Example:

eos_achievements_query_player_achievements(local_user_id, local_user_id, function(_result)
{
    if (_result.result_code == EpicResult.Success)
    {
        show_debug_message($"Loaded {eos_achievements_get_player_achievement_count(_result.user_id, _result.target_user_id)} achievements for {_result.target_user_id}");
    }
});
The above code queries the local player's own achievement progress.

eos_achievements_copy_achievement_definition_by_index¶

Epic Online Services Function: EOS_Achievements_CopyAchievementDefinitionByIndex

Fetches an achievement definition by index from the cached data populated by eos_achievements_query_definitions.

Note

This is the deprecated (V1) definition shape - prefer eos_achievements_copy_achievement_definition_v2_by_index for new code, which reports separate unlocked/locked display text instead of a single ambiguous pair.


Syntax:

eos_achievements_copy_achievement_definition_by_index(index)
Argument Type Description
index Real Index of the definition, between 0 and eos_achievements_get_achievement_definition_count - 1.


Returns:

EpicAchievementsDefinition

Warning

Returns undefined if index is out of range or no definitions have been queried yet - check eos_api_last_error for the reason.

eos_achievements_copy_stat_threshold_by_index¶

Epic Online Services Function: EOS_Achievements_CopyAchievementDefinitionV2ByAchievementId

Fetches one stat threshold entry (a stat name and the value it must reach) from the given achievement's definition, by index. Internally this fetches the achievement's V2 definition and indexes into its embedded threshold list - it does not require you to have called eos_achievements_query_definitions again beforehand, but the achievement itself must exist on the backend.


Syntax:

eos_achievements_copy_stat_threshold_by_index(achievement_id, index)
Argument Type Description
achievement_id String ID of the achievement whose thresholds to read.
index Real Index of the threshold entry, between 0 and the achievement's stat_thresholds_count.


Returns:

EpicStatThreshold

Warning

Returns undefined if achievement_id is invalid or index is out of range - check eos_api_last_error for the reason.

eos_achievements_unlock_achievements¶

Epic Online Services Function: EOS_Achievements_UnlockAchievements

Directly unlocks one or more achievements for a player. Most games instead unlock achievements automatically on the backend once the underlying stats reach their thresholds - use this for achievements that aren't stat-driven.

This function operates asynchronously, which means that it does not immediately return the requested result. Instead, upon completion of the task, it will trigger the Callback.


Syntax:

eos_achievements_unlock_achievements(user_id, achievement_ids, callback=undefined)
Argument Type Description
user_id String The Product User ID of the player to unlock achievements for.
achievement_ids Array of String The IDs of the achievements to unlock.
callback Function Function invoked when the request completes.


Returns:

N/A


Triggers:

Callback

Called once when the unlock request completes.

Key Type Description
result EpicAchievementsUnlockAchievementsCallbackInfo The result of the request.


Example:

eos_achievements_unlock_achievements(user_id, ["ach_first_win", "ach_no_deaths"], function(_result)
{
    if (_result.result_code == EpicResult.Success)
    {
        show_debug_message($"Unlocked {_result.achievements_count} achievement(s)");
    }
});
The above code unlocks two achievements directly for the given player.

eos_achievements_add_notify_achievements_unlocked_v2¶

Epic Online Services Function: EOS_Achievements_AddNotifyAchievementsUnlockedV2

Registers to be notified whenever an achievement is unlocked for any locally logged-in user, however it was unlocked (through eos_achievements_unlock_achievements or automatically via stats). If the returned notification ID is valid, call eos_achievements_remove_notify_achievements_unlocked when you no longer need it (e.g. on room/game end).

This function operates asynchronously, which means that it does not immediately return the requested result. Instead, upon completion of the task, it will trigger the Callback.


Syntax:

eos_achievements_add_notify_achievements_unlocked_v2(callback=undefined)
Argument Type Description
callback Function Function invoked every time an achievement unlocks.


Returns:

Real

A notification ID, or 0 if registration failed.


Triggers:

Callback

Called once per achievement unlock.

Key Type Description
result EpicAchievementsUnlockedV2CallbackInfo Details of the unlocked achievement.


Example:

global.achievement_notify_id = eos_achievements_add_notify_achievements_unlocked_v2(function(_result)
{
    show_debug_message($"Achievement unlocked: {_result.achievement_id}");
});
The above code registers a persistent listener for achievement unlocks.

The deprecated (V1) achievement definition shape, as returned by eos_achievements_copy_achievement_definition_by_index/eos_achievements_copy_achievement_definition_by_id. Prefer EpicAchievementsDefinitionV2 for new code.

Member Type Description
achievement_id String The ID of the achievement.
display_name String The unlocked display name.
description String The unlocked description.
locked_display_name String The locked display name.
locked_description String The locked description.
hidden_description String The description shown for a hidden achievement before it's unlocked.
completion_description String Flavor text shown once the achievement completes.
unlocked_icon_id String ID of the icon shown when unlocked.
locked_icon_id String ID of the icon shown when locked.
is_hidden Boolean Whether the achievement is hidden until unlocked.
stat_thresholds_count Real Number of entries in stat_thresholds.
stat_thresholds Array of EpicAchievementsStatThresholds The stat name/threshold pairs required to unlock this achievement.

EpicAchievementsDefinitionV2¶

The current achievement definition shape, as returned by eos_achievements_copy_achievement_definition_v2_by_index. Unlike EpicAchievementsDefinition this reports separate display text for the unlocked and locked states rather than one ambiguous pair.

This struct is referenced by the following functions:

  • eos_achievements_copy_achievement_definition_v2_by_index


Member Type Description
achievement_id String The ID of the achievement.
unlocked_display_name String The display name shown once unlocked.
unlocked_description String The description shown once unlocked.
locked_display_name String The display name shown while locked.
locked_description String The description shown while locked.
flavor_text String Flavor text for the achievement.
unlocked_icon_url String URL of the icon shown when unlocked.
locked_icon_url String URL of the icon shown when locked.
is_hidden Boolean Whether the achievement is hidden until unlocked.
stat_thresholds_count Real Number of stat thresholds behind this achievement (fetch them individually with eos_achievements_copy_stat_threshold_by_index).
