Ecom

Epic Online Services Interface: Ecom Interface

The Ecom (E-Commerce) Interface lets you query and sell your game's catalog items, manage entitlements, and check ownership - covering the full loop from browsing offers to completing a purchase through the Epic Overlay.

eos_ecom_query_ownership

Epic Online Services Function: EOS_Ecom_QueryOwnership

Queries the ownership status for a list of catalog item IDs defined with Epic Online Services. The result is cached locally - read it back with eos_ecom_get_item_ownership_count and eos_ecom_copy_item_ownership_at_index once the callback fires with success. A fresh call to this function replaces the previously cached result for local_user_id.

Warning

You should only use this function for startup checks - use Auth or Connect events to more reliably determine when to query for ownership changes.

This function operates asynchronously, which means that it does not immediately return the requested result. Instead, upon completion of the task, it will trigger the Callback.


Syntax:

eos_ecom_query_ownership(local_user_id, catalog_item_ids, catalog_namespace, callback=undefined)
Argument Type Description
local_user_id String The Epic Account ID of the local user whose ownership is being queried.
catalog_item_ids Array of String The catalog item IDs to query.
catalog_namespace String The product namespace to use, or an empty string "" to use the
configured default namespace.
callback Function Called once the query completes.


Returns:

N/A


Triggers:

Callback

Fires once with the query result.

Key Type Description
result EpicEcomQueryOwnershipCallbackInfo


Example:

eos_ecom_query_ownership(local_user_id, ["catalog_item_1", "catalog_item_2"], "", function(_result)
{
    if (_result.status == EpicResult.Success)
    {
        var _count = eos_ecom_get_item_ownership_count(local_user_id);
        for (var i = 0; i < _count; i++)
        {
            var _entry = eos_ecom_copy_item_ownership_at_index(local_user_id, i);
            show_debug_message($"{_entry.id}: {_entry.ownership_status}");
        }
    }
});
The above code queries ownership for two catalog items and lists the cached result once resolved.

eos_ecom_query_ownership_by_sandbox_ids

Epic Online Services Function: EOS_Ecom_QueryOwnershipBySandboxIds

Queries the ownership status of catalog items across a set of sandboxes, for the currently logged in user. Unlike eos_ecom_query_ownership, this can be queried using an eos_connect_login logged in user, and does not require an Epic Account. The result is cached locally - read it back with eos_ecom_get_sandbox_ownership_count and eos_ecom_copy_sandbox_ownership_at_index.

This function operates asynchronously, which means that it does not immediately return the requested result. Instead, upon completion of the task, it will trigger the Callback.


Syntax:

eos_ecom_query_ownership_by_sandbox_ids(local_user_id, sandbox_ids, callback=undefined)
Argument Type Description
local_user_id String The Product User ID of the local user whose ownership is being queried.
sandbox_ids Array of String The sandbox IDs to query ownership within.
callback Function Called once the query completes.


Returns:

N/A


Triggers:

Callback

Fires once with the query result.

Key Type Description
result EpicEcomQueryOwnershipBySandboxIdsCallbackInfo

eos_ecom_query_entitlements

Epic Online Services Function: EOS_Ecom_QueryEntitlements

Queries the backend for the local user's entitlements. Any Epic Games-based entitlements can only be queried from the running application defined by the Product ID configured with Extension Options. The result is cached in the SDK's own entitlement cache - read it back with eos_ecom_get_entitlements_count/eos_ecom_get_entitlements_by_name_count and the matching eos_ecom_copy_entitlement_* accessors.

This function operates asynchronously, which means that it does not immediately return the requested result. Instead, upon completion of the task, it will trigger the Callback.


Syntax:

eos_ecom_query_entitlements(local_user_id, entitlement_names, include_redeemed, catalog_namespace, callback=undefined)
Argument Type Description
local_user_id String The Epic Account ID of the local user whose entitlements are being queried.
entitlement_names Array of String Optional list of entitlement names to query. Pass an empty
array to query all entitlements for the product.
include_redeemed Boolean Whether to include already-redeemed entitlements in the result.
catalog_namespace String The product namespace to use, or an empty string "" to use the
configured default namespace.
callback Function Called once the query completes.


Returns:

N/A


Triggers:

Callback

Fires once with the query result.

Key Type Description
result EpicEcomQueryEntitlementsCallbackInfo

eos_ecom_checkout

Epic Online Services Function: EOS_Ecom_Checkout

Starts a checkout for one or more offers. This opens the Epic Overlay's purchase flow; the callback fires once the player finishes, cancels, or the purchase flow otherwise closes.

Note

EpicResult.EcomPurchaseProcessing can be returned in the callback if the player closed the purchase flow overlay after clicking the purchase button - the purchase may still be processing, so re-query entitlements shortly afterward rather than treating this as a hard failure.

This function operates asynchronously, which means that it does not immediately return the requested result. Instead, upon completion of the task, it will trigger the Callback.


Syntax:

eos_ecom_checkout(local_user_id, offer_ids, catalog_namespace, callback=undefined)
Argument Type Description
local_user_id String The Epic Account ID of the local user starting the checkout.
offer_ids Array of String The offer IDs to purchase.
catalog_namespace String The product namespace to use, or an empty string "" to use the
configured default namespace.
callback Function Called once the checkout flow completes.


Returns:

N/A


Triggers:

Callback

Fires once with the checkout result.

Key Type Description
result EpicEcomCheckoutCallbackInfo

Releases a transaction handle obtained from eos_ecom_copy_transaction_by_index or eos_ecom_copy_transaction_by_id. Using the handle after release is invalid.
